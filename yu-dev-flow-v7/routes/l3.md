# L3 — Coordinate

Use L3 only when at least two independently deliverable slices have a real dependency, handoff, or context-separation need.

Choose the chain:

- Use `/wayfinder` when decision fog spans more than one session. It needs an issue-tracker configuration in the repository or current context.
- Otherwise use `/grill-with-docs` → `/to-spec` → `/to-tickets` → `/implement`. `/to-spec` and `/to-tickets` need issue-tracker and triage-label configurations in the repository or current context.

If a required configuration file is missing, invoke `/setup-matt-pocock-skills` and pause the selected chain until setup completes. Do not install or simulate setup.

For the selected chain, invoke only these skills:

- `/wayfinder`
- `/grill-with-docs`
- `/to-spec`
- `/to-tickets`
- `/implement`

Hand off slices, blockers, and execution order explicitly. If no real dependency or context benefit remains, downgrade to L2 or L1.
