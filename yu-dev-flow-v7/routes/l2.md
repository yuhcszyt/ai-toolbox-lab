# L2 — Contract

Use L2 when implementation requires a stable contract for an API, data shape, state transition, transaction, module responsibility, or several interacting business rules.

Before the chain, check the setup gate in the parent `SKILL.md`:

- If either configuration is absent from the repository and the current context, invoke `/setup-matt-pocock-skills` first and pause this route until it completes.
- If both configurations are present in the repository or current context, continue without setup.

Handoff:

1. Invoke `/grill-with-docs`.
2. After the decisions are confirmed, invoke `/to-spec`.
3. After the spec has no implementation blocker, invoke `/implement`.

If a completed spec already satisfies the contract stage, skip `grill-with-docs` and/or `to-spec` as appropriate; never rebuild a valid artifact.
