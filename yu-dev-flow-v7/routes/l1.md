# L1 — Clarify

Use L1 when a small set of blocking uncertainties can be resolved without fixing a stable shared contract.

Handoff:

1. Invoke `/grill-with-docs` to resolve only the decisions that can change implementation.
2. When those decisions are resolved, invoke `/implement`.

If the discussion reveals an API, data, state, transaction, module-responsibility, or multi-rule contract, promote to L2 and run its setup gate before `to-spec`. Do not trigger setup for an ordinary L1 route.
